# Merchant logos

Drop a logo here and it replaces the downloaded one everywhere in the app (Transactions,
Recurring and Patterns). Name the file after the merchant as it appears in the app, in lower
case with dashes:

| Shown as          | File name                |
| ----------------- | ------------------------ |
| Spotify           | `spotify.png`            |
| Georgia Power     | `georgia-power.png`      |
| Woofs Sports Bar  | `woofs-sports-bar.svg`   |

png, svg, webp, jpg and jpeg all work. Square images at 128 px or larger look best.
